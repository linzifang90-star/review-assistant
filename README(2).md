# 好评助手

扫码几十秒，让顾客愿意写的好评。

## 痛点

- 商家每周都有优质好评的 KPI，但顾客嫌写评价麻烦；
- 请顾客写好评常常变成“把手机交给商家写”，既不合规也不可信。

## 怎么做

顾客扫商家二维码 → 订单尾号核验（一单一评）→ 选菜品标签、打星 → AI 把顾客自己选的真实体验整理成一段可编辑的评价草稿 → 顾客自己复制，到大众点评 / 美团 / 抖音发布。

商家端：创建门店、配置菜品与标签、每店一个固定 8 位门店码（二维码与链接永久有效）、看板统计（扫码 / 生成草稿 / 公开评价 / 私下反馈）。

## 合规红线（本项目坚持的）

- 不自动发布：草稿只进顾客剪贴板，发布由顾客本人完成；
- 不预设五星：评分、标签、原话都由顾客自己选；
- 低分私下反馈：1–2 星不引导公开，只进商家可见的私下反馈；
- 一单一评：同一订单尾号只能评价一次。

## 本地运行

单文件应用：全部源码都在 `index.html` 一个文件里（HTML + CSS + JS，约 207KB），不走 npm / 构建工具链，无需安装依赖，无后端服务器，数据保存在浏览器 localStorage。

- 直接用浏览器打开 `index.html` 即可运行；
- 也可部署到任意静态托管（Qoder Sites / Vercel / Netlify / GitHub Pages）。
- AI 草稿默认使用本地模板；如需接真实模型，在商家端“AI 设置”中填写 Base URL、API Key 与模型名，并用“测试连接”验证（Key 只保存在本机浏览器，不上传）。

## 项目结构

- `index.html` —— 全部源码（单文件应用）
