## 好评助手 UI 重构（unslop 全量改版）

**产物**：`dist/index.html`（单文件，244KB，零第三方依赖、零外链）。未改动任何业务逻辑，只重写样式层与三处模板结构。JS 交互冒烟测试全部通过、无控制台报错。

**设计方向**：石墨玻璃仪器台。中性灰单色阶（#0A0B0D → #1C1F25），单一强调色保留品牌朱红 #E0462C，金色仅用于星级，发丝描边（white 7%/14%），圆角 16/10/8，动效曲线 cubic-bezier(.22,.61,.36,1)，时长 120/180/300。

**结构改动**
- 控制台：`page-head` + 3 列 Bento（近 7 天趋势 span2 + 平均星级 + 3 张 KPI），门店卡去掉迷你柱状图、四按钮改三 ghost + 一个 trash icon，新增「最近一条评价」摘要行。
- 登录页：左右分栏（左品牌文案 + 三条真实功能事实，右玻璃卡）；≤960px 单列顶对齐。
- 顾客页：步骤条与卡片同宽（原为负 margin 出血导致错位），新增「已核验门店 · 一单一评」眉标。
- 404 / 下架页：删掉暖色卡通插画，改中性 `nf-mark` 图标块。

**氛围层**：原生 WebGL 点场（`initAmbient()`，约 80 行，无 Three.js 依赖），鼠标视差 + 缓慢上浮，`prefers-reduced-motion` 与宽度 <900px 不启动。

**动效**：`.rise` 入场 8px 上浮、IntersectionObserver 滚动揭示（仅编辑页 `.ed-sec`）、hover 只改 color/border/background。

**已修细节**：星级 SVG 硬编码暖色 → CSS 变量；平台图标底色改中性；Toast 从顶部改左下（顾客页底部居中），不再遮挡顶栏；编辑页保存按钮不再拉伸满宽并与卡片右边缘对齐；漏斗百分比标签缩短避免换行；`字号 <11px` 全部提到 11px。

**留档**：`.unslop/before|after/*.png`（已加入 .gitignore）。

## 第二轮打磨（同日，继续优化）

**产物仍是** `dist/index.html`（252KB，零依赖）。19 项交互冒烟全 PASS，零控制台报错。

**修掉的真实缺陷**
1. 背景色带：`radial-gradient` 终点写成 `transparent`（= rgba(0,0,0,0)），朱红淡出时经过灰黑产生浑浊色带。改为同色零透明，并在渐变之上压一层 `mix-blend-mode:overlay` 的高频噪点打散 8bit 台阶。移动端（≤820px）关 canvas，只留静态极光。
2. 移动端顶栏：`AI 引擎` 的 span 被隐藏后只剩齿轮图标，挤成一颗圆点。改为「⋯」弹出菜单（AI 草案引擎 / 退出登录），点外部或 Esc 收起。
3. 抽屉信息架构：域名设置原占首屏一整块。重排为 评分 → 二维码（含门店码读数）→ 图表 → 漏斗 → 评价列表 → 折叠[站点域名] / 折叠[门店资料与演示数据]。
4. 顾客侧技术文案：原会显示「AI 接口未配置完整（需填齐接口地址/模型名/密钥）」和风控参数（每店每日上限 5 条）。全部改为中性表述，原因只 `console.info` 给商家。
5. 浅色残留：草稿页错误块内联 `background:#FBF1EE`，在暗色页上是一张刺眼白纸，改为 `var(--danger-soft)`。
6. 二维码静区：`paintQR` 从左上角画 n 个模块，白卡按 (n+8) 算尺寸却把内容画在角上，导致 QR 偏上/偏左。三处（桌贴、分享卡、qrCanvasFor）统一按 `+4*mod` 偏移居中。
7. 桌贴店名被裁：画完右对齐的 "REVIEW BOOSTER" 后没复位 `textAlign`，店名右对齐到 M 溢出画布左侧。
8. 漏斗同组数字渲染两遍（大数字块 + 条形行）。条形行只留百分比，分母说明进 `title`。
9. 星级分布条全用 `--ink-2` 一样亮，读不出好评集中度。改金色 + 按星级递减 opacity（1/.7/.48/.32/.2）。
10. 空账号显示「全部已通过审核」；空门店仍显示搜索/排序；`—` 在 46px 下像一道划痕。

**新增**
- 门店资产卡：A6 桌贴按新设计语言重做（浅纸底、发丝线、mono 门店码、无色块横条），新增 1200×630 暗色分享卡 `shareCanvas()`，四宫格下载（复制链接/二维码图片/桌贴/分享卡）。
- KPI 数字滚动 `animateNums()`：`data-num` 驱动，520ms cubic ease-out，无回弹，尊重 `prefers-reduced-motion`。
- 焦点态从「朱红整圈边框」（像报错）改为中性提亮 + 极淡主色光晕。

**教训**：这个项目里所有 `<div class="hint">` 都可能被业务规则污染（「不少于 5 个字」「1–100000 的整数」）。校验规则该交给 `.err` 在出错时出现，不该常驻在字段下方。

## 第四轮打磨（同日，柱状图配色 + 主题换色）

**1. 柱状图从灰阶改暖金时间轴**
- `.chart .cbar` 原为 `rgba(255,255,255,.14)`，只有「今天」是朱红。改为 `BAR_TONES` 六档暖金（#96693A → #D5A050）按日序递进，今天仍落 `--primary`；空日保持 `rgba(255,255,255,.07)` 细柱，形成「有数据才有色」的对比。
- 色阶用 `--bar` 内联变量注入，CSS `background-color:var(--bar,...)` 生效；`:hover` 用 `filter:brightness()` 而非换色，渐变不会跳。
- 先试过顶部白色渐变高光，矮柱会变成「金块」且色差被高光盖住，退回纯色 + `inset 0 1px 0 rgba(255,255,255,.18)` 一条顶部亮线。有数据的最小柱高 6→10px，避免 3px 圆角看起来像点。

**2. 主题从纯黑改深靛蓝**
- 背景 `#0A0B0D` → `#0B1220`，surface `#101216/#16181D/#1C1F25` → `#111A2A/#182231/#1F2A3B`，ink 三档与 line 同步偏蓝（`rgba(198,216,255,.09)`）。
- 氛围层 `#ambient::before` 由「朱红 + 两片白色雾」改为红蓝双光：左上 `rgba(224,70,44,.11)`，右上 `rgba(74,124,240,.22)`，底部 `rgba(58,88,184,.19)`；移动端静态极光同款双光。
- 粒子 shader 颜色 `vec3(.80,.83,.88)` → `vec3(.74,.82,.98)`。
- **坑：所有吸顶/固定条都是旧底色的半透明硬编码**（topbar/编辑器导航/底部保存条/步骤条/modal 面板）。只改 `:root` 会留下比内容更暗的黑带。统一换成 surface 系 `rgba(17,26,42,.88–.94)`，玻璃条才和内容连成一体。
- 同类硬编码一并清掉：`.bento-card:hover` `#121419` → `var(--surface-2)`，`:active` → `var(--surface-3)`，占位/禁用文字 `#5C626A/#4A5057/#4C5158` → 偏蓝灰；分享卡背景 `#0E1013` → `#0C111B`。
